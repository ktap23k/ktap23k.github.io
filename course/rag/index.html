RAG từ cơ bản đến nâng cao

Học cách cho LLM "đọc" tài liệu của riêng bạn và trả lời có dẫn nguồn. Khoá học đi từ embedding và RAG 60 dòng code đầu tiên, qua chunking, hybrid search, reranking, đến đánh giá có hệ thống, GraphRAG, Agentic RAG và những gì cần để chạy ổn định trên production.

Bắt đầu học →

Bạn sẽ học được gì

  • Hiểu bản chấtVì sao LLM bịa, khi nào RAG là lời giải và khi nào fine-tuning hay long-context hợp hơn.
  • Indexing đúng cáchLàm sạch dữ liệu tiếng Việt, chọn chiến lược chunking, gắn ngữ cảnh cho từng chunk.
  • Retrieval chất lượng caoHybrid search BM25 + vector, RRF, reranker, biến đổi và định tuyến truy vấn.
  • Trả lời có căn cứPrompt grounding, trích dẫn nguồn, biết nói "không biết" và quản lý context window.
  • Đo lường đượcRecall@k, MRR, nDCG, faithfulness; xây golden set và vòng lặp cải tiến có số liệu.
  • Kiến trúc nâng caoGraphRAG, Agentic RAG, RAG đa phương thức, bảo mật và vận hành production.

Yêu cầu đầu vào

  • Python cơ bản: hàm, list/dict, đọc file, cài package bằng pip.
  • Đã từng gọi API của một LLM (OpenAI, Anthropic, Gemini, Ollama… đều được). Code trong khoá học không phụ thuộc nhà cung cấp.
  • Không cần nền tảng machine learning — các khái niệm cần thiết đều được giải thích từ đầu.

Cách học hiệu quả

  • Học theo thứ tự: mỗi module dựa trên module trước. Module 1–2 là bắt buộc, module 3–5 có thể chọn theo nhu cầu.
  • Gõ lại code của các bài Lab với chính tài liệu của bạn (quy trình nội bộ, README, ghi chú…) — dữ liệu thật dạy nhiều hơn dữ liệu mẫu.
  • Làm phần "Kiểm tra nhanh" cuối mỗi bài trước khi mở đáp án, rồi bấm "Đánh dấu đã học" để theo dõi tiến độ.
  • Đo trước khi tối ưu: từ Module 4 trở đi, mọi thay đổi nên đi kèm một con số trên bộ đánh giá của bạn.
